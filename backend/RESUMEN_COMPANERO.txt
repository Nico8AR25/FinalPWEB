Todo el backend está listo. Solo necesitas configurar PostgreSQL.

═══════════════════════════════════════════════════════════════
  ⚡ LO QUE TIENES QUE HACER (5 MINUTOS)
═══════════════════════════════════════════════════════════════

1️⃣  Crear archivo .env en la carpeta backend/
   
   Contenido:
   ────────────────────────────
   DB_USER=postgres
   DB_PASS=tu_password_aqui
   DB_NAME=streamboost_db
   DB_HOST=localhost
   ────────────────────────────
   
   ⚠️  Reemplaza "tu_password_aqui" con tu contraseña real de PostgreSQL

2️⃣  Crear la base de datos en PostgreSQL
   
   En psql o pgAdmin ejecuta:
   CREATE DATABASE streamboost_db;

3️⃣  Instalar dependencias (si no están)
   
   cd backend
   npm install

4️⃣  Ejecutar las migraciones
   
   npx sequelize-cli db:migrate
   
   Esto crea automáticamente las 3 tablas:
   - users
   - streams  
   - donacions

5️⃣  Iniciar el servidor
   
   node server.js
   
   Si ves: "Servidor escuchando en el puerto 3080" → ¡LISTO! ✅
